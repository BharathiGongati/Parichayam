Parichayam Visual Flow Diagrams

Business-friendly flow maps for admin and owner training.

1. End-to-End User Journey

Index PageUser lands on the website and sees brand trust and signup CTA.
→
Auth PageUser signs in or starts registration.
→
Trial or Paid StartUser starts free trial or goes to checkout.
→
DashboardUser completes profile and begins discovery.
→
MatchesBackend ranks and returns live candidates.

2. Matchmaking Engine

Hard Filters
  • Opposite gender only
  • No self profile
  • No blocked, hidden, suspended profiles
  • Same-gotra block if hard policy is enabled
Score Factors
  • Age fit
  • Community fit
  • Location fit
  • Education fit
  • Income fit
  • Completeness, activity, trust, kundali
Limited Bonus LayerPaid and boosted profiles receive a capped visibility bonus.
→
Final RankHighest total score appears first in Today’s Matches and search-driven discovery.

3. Admin Controls and Business Impact

Admin Settings
  • Auth and OTP
  • Payment settings
  • Kundali settings
  • Dashboard Builder
  • Form Builder
Business Outcome
  • Signup flow changes
  • Checkout behavior changes
  • Member dashboard visibility changes
  • Profile quality changes
  • Match quality changes

4. Daily Operations Loop

MorningNew registrations, verification queue, trial expiry, payments, agent requests.
→
MiddayMatch quality spot-check, incomplete profile review, support follow-up.
→
EveningRevenue summary, settings review, backlog review, business risk review.

5. Verification Flow

Member UploadAadhaar or income proof is submitted.
→
Verification QueueAdmin reviews document quality and consistency.
→
Approve or RejectValid documents improve trust score; invalid ones return for correction.
→
Trust ImprovementVerified profiles rank better and look more serious to families.

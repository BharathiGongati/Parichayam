# Parichayam Canva Design Brief

## Objective
Turn the Parichayam SOP into a premium business document and training pack suitable for:
- business owner
- super admin
- operations manager
- verification staff
- matchmaker staff

## Primary Deliverables
- printable SOP PDF
- admin training checklist
- visual process flow document

## Brand Direction
- Premium Indian matrimonial tone
- Elegant, trustworthy, culturally warm, business-ready
- Avoid flashy startup visuals
- Avoid generic corporate blue themes

## Color Palette
- Maroon: `#7B1C2E`
- Deep Maroon: `#4A0E1A`
- Gold: `#C9963A`
- Light Gold: `#E8C06A`
- Cream: `#FDF6EC`
- White: `#FFFDF9`

## Typography
- Heading: Playfair Display, Cormorant Garamond, or Libre Baskerville
- Body: DM Sans, Open Sans, Lato, or Source Sans

## Layout Style
- Large elegant title blocks
- Clean section dividers
- Spacious margins
- Checklist panels
- Warning callout boxes
- Example scenario cards
- Simple flow diagrams with arrows

## Visual Sections to Include
- Cover page
- system overview
- user journey
- page-wise SOP
- matchmaking logic
- admin control guide
- risk and edge cases
- daily operations
- training checklist
- visual flow diagrams
- final recommendations

## Recommended Canva Workflow
1. Open Canva Docs
2. Paste contents of `parichayam-canva-master-copy.md`
3. Apply brand colors and fonts
4. Break content into pages
5. Convert key flows into boxes and arrows
6. Export as PDF

## Recommended Page Order
1. Cover
2. System Overview
3. End-to-End System Flow
4. Page-Wise SOP Part 1
5. Page-Wise SOP Part 2
6. Matchmaking Logic
7. Admin Control Guide
8. Risk and Edge Cases
9. Daily Operations SOP
10. Admin Training Checklist
11. Visual Flow Diagrams
12. Final Recommendations
